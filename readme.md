# Vanilla Vite Project

Простой стартовый шаблон для проекта на **Vanilla JavaScript** с использованием **Vite**.

---

## 📦 Установка

1. **Клонируйте репозиторий** (если ещё не сделали этого):
  ```bash
   git clone [ссылка-на-репозиторий]
   cd [название-папки]
  ```
2. **Установите зависимости**:
  ```bash
   npm install
  ```
3. **Запустите проект в режиме разработки**:
  ```bash
   npm run dev
  ```
   Откройте [http://localhost:5173](http://localhost:5173) в браузере.

---

## 🛠 Сборка проекта

- **Для сборки проекта в продакшн**:
  ```bash
  npm run build
  ```
  Готовые файлы будут в папке `dist`.
- **Для предварительного просмотра продакшн-сборки**:
  ```bash
  npm run preview
  ```

## 🔧 Конфигурация Vite

Файл `vite.config.js` позволяет настроить сборку под ваши нужды. Например, можно добавить плагины, изменить пути или настроить сервер разработки.

Пример базовой конфигурации:

```js
import { defineConfig } from 'vite';

export default defineConfig({
  base: './', // Для корректной работы при развёртывании на GitHub Pages
  server: {
    port: 3000, // Порт для dev-сервера
  },
});
```

## 🚀 Развёртывание

### GitHub Pages

1. Убедитесь, что в `vite.config.js` указано `base: './'`.
2. Соберите проект: `npm run build`.
3. Загрузите содержимое папки `dist` в ветку `gh-pages` или используйте [GitHub Actions](https://github.com/marketplace/actions/deploy-to-github-pages).

### Netlify/Vercel

1. Загрузите проект в репозиторий.
2. Подключите репозиторий к Netlify/Vercel.
3. Укажите команду для сборки: `npm run build`.
4. Укажите папку для публикации: `dist`.
